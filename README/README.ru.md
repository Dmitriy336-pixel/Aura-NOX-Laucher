# Aura NOX Launcher

[English](README.en.md) · [Українська](README.uk.md)

Лаунчер для Windows на Python и PySide6 (Qt): окно с плитками программ, правая панель с быстрыми кнопками, командная строка, заметки, темы оформления и звуки событий. Работает с клавиатуры и мышью, может жить в фоне и вызываться горячей клавишей.

## Возможности

- **Плитки.** Любая программа, ярлык или `.bat` становится плиткой. Плитки можно переставлять мышью или клавишами, красить в любой цвет, давать им свои иконки. Иконка подбирается сама: из папки `icon_pack`, из самой программы или из ярлыка.
- **Быстрые клавиши плиток.** У каждой плитки своя клавиша (цифры и буквы, на любой раскладке). Нажатие сразу запускает плитку.
- **Правая панель.** Кнопки настроек, командной строки, заметок, блокировки перетаскивания и режима высокой производительности. Лишние кнопки можно спрятать.
- **Командная строка.** Вызывается из любой программы горячей клавишей. Есть встроенные команды и свои, навигация по папкам и файлам, избранные папки, быстрые заметки и история команд (см. ниже). Пока строка открыта, экран под ней размывается и затемняется (настраивается, можно выключить).
- **Поиск программ.** Плитка с лупой (или сама «+», по настройке) ищет программу по названию среди ярлыков меню «Пуск», рабочего стола и программ из реестра; если не нашлось, можно поискать на диске или выбрать файл вручную.
- **Три языка.** Русский, English, Українська. Язык выбирается при первом запуске и меняется в настройках.
- **Заметки.** Обычные `.md`-файлы в отдельной папке: вкладки, живое оформление Markdown, панель форматирования, поиск по названию и тексту, закрепление, автосохранение.
- **Поиск по настройкам.** Строка поиска в окне настроек находит нужный пункт и прокручивает к нему.
- **Темы.** Цвета, скругления, шрифты, картинки и текстуры кнопок, светлый и тёмный режим.
- **Звуки.** Свой звук на каждое событие, общая громкость и переключатель.
- **Фоновый режим.** Лаунчер прячется целиком и возвращается горячей клавишей. Автозапуск с Windows.
- **Справка внутри.** Первый запуск с условиями и короткой инструкцией, вкладки «FAQ» и «О программе» в настройках.
- **Один экземпляр.** Повторный запуск не создаёт второе окно, а показывает уже работающее.

## Требования

- Windows 10 или 11 (программа использует вызовы WinAPI).
- Python 3.13 (проверено на нём).
- Пакеты: `PySide6`, `Pillow`.

```
pip install PySide6 pillow
```

## Запуск

```
python main.py
```

Ключ `--background` запускает лаунчер сразу спрятанным (его использует автозапуск).

## Управление

### Главное окно

| Клавиши | Действие |
|---|---|
| Стрелки | выбрать плитку; на панели справа вверх и вниз выбирают кнопку, влево возвращает к плиткам |
| Tab | перенести выбор между плитками и панелью |
| Enter | запустить плитку, добавить программу на «+» (или открыть поиск на лупе) или нажать кнопку панели |
| Клавиша плитки | сразу запустить плитку |
| Delete | меню выбранной плитки (удалить, цвет, иконка) |
| Правый клик | то же меню у плитки под курсором |
| Ctrl + стрелки | передвинуть выбранную плитку |
| Мышь | зажать плитку и потянуть, чтобы поменять местами |
| F2 | настройки |
| Ctrl+Q | полностью закрыть лаунчер |

Перетаскивание можно заблокировать кнопкой ⇅ на панели.

### Глобальные горячие клавиши

Работают из любой программы. Все три меняются в настройках.

| По умолчанию | Действие |
|---|---|
| Ctrl+Alt+Space | показать или спрятать лаунчер (фоновый режим) |
| Ctrl+Alt+T | командная строка |
| Ctrl+Alt+N | заметки |

### Командная строка

Tab подставляет подсказку, стрелки вверх и вниз выбирают её, Enter выполняет, PgUp и PgDn листают длинный ответ и страницы подсказок, Esc закрывает. Если поле пустое, стрелка вверх достаёт прошлые команды (последние 50, они хранятся и между запусками), вниз возвращает к новым. Команда `помощь` показывает весь список. Размытие фона включается и настраивается в «Настройки», «Внешний вид», «Дополнительные настройки», «Размытие фона» (сила, затемнение, плавность; в светлой теме фон осветляется); клик по размытому фону закрывает строку. При английском и украинском интерфейсе команды показываются английскими именами (`help`, `desk`, `calc`), русские имена работают в любом языке.

Встроенные команды (у многих есть короткие и английские имена):

| Команда | Что делает |
|---|---|
| `помощь` | список команд |
| `настройки`, `скрыть`, `выход` | управление самим лаунчером |
| `рб` | рабочие столы: `рб 2` перейти, `рб +` новый, `рб -` закрыть |
| `окно` | переключиться на открытое окно |
| `громкость` | системная громкость: `+`, `-`, `выкл` |
| `блок` | заблокировать компьютер |
| `выключить`, `перезагрузить`, `отмена` | выключение и перезагрузка с задержкой, чтобы успеть передумать |
| `производительность` | режим высокой производительности |
| `заметки` | открыть заметки |
| `папка` | папки и файлы: `папка загрузки\...`, после пути пробел покажет действия (см. ниже) |
| `избранное` | избранные папки: `избранное`, `избранное убрать имя` |
| `запуск` | запустить плитку по названию: `запуск obs` |
| `записать` | быстрая заметка: `записать купить хлеб` |
| `поиск` | поиск в интернете: `поиск погода` |
| `скрин` | снимок экрана (вырезка Win+Shift+S) |
| `счёт` | калькулятор: `счёт 2+2*3` |
| `условия` | условия использования |

**Свои команды** добавляются в настройках, в разделе «Команды», и хранятся в `commands.json`. Три вида действий:

- **open**: открыть программу, файл, папку или сайт;
- **set**: открыть набор из нескольких пунктов по очереди (по одному в строке);
- **shell**: выполнить команду командной строки Windows.

В цели можно написать `{}`: туда подставится текст, введённый после команды. Так получаются быстрые поиски, например `https://www.youtube.com/results?search_query={}` для команды `kk что-нибудь`.

### Папки и файлы (команда `папка`)

Пишите `папка загрузки\`, и подсказки покажут, что внутри: Tab заходит в выбранную папку, `..\` поднимает на уровень выше, подсказки листаются PgUp и PgDn. Путь начинается с готового имени (`загрузки`, `документы`, `рабочий`, `изображения`, `видео`, `музыка`, `автозагрузка`, `домой`), с диска (`c:`) или с имени из избранного. Enter открывает папку в проводнике, а файл запускает.

Пробел после целого пути показывает действия над ним:

| Действие | Что делает |
|---|---|
| `открыть` | открыть в проводнике (файл запустить) |
| `терминал` | терминал в этой папке |
| `код` | открыть в VS Code |
| `путь` | скопировать путь в буфер обмена |
| `показать` | показать в проводнике |
| `список` | что лежит внутри |
| `найти текст` | найти по имени внутри, с подпапками |
| `создать имя` | создать подпапку |
| `плитка` | добавить плиткой на главный экран |
| `закрепить` или `закрепить имя` | добавить в избранное |

У действий есть и английские имена (`open`, `term`, `code`, `path`, `show`, `ls`, `find`, `new`, `tile`, `pin`). Избранные папки хранятся в `favorites.json`, а команда `избранное` показывает их список.

## Язык

Языки: русский, English, Українська. Выбор появляется при первом запуске, потом его можно сменить в «Настройки», «Общие», «Язык». После смены лаунчер предлагает перезапуститься: тексты строятся при старте. Названия языков: «Русский», «English», «Українська»; в английском и украинском интерфейсе русский подписан просто «Ru».

Строк, у которых нет перевода, лаунчер показывает по-русски, ничего не ломается.

## Первый запуск, условия, справка

- **Первый запуск.** Окно из трёх шагов: язык, условия использования, короткая инструкция. Показывается один раз и снова только если версия условий изменится (в `settings.json` это поле `terms_seen`).
- **Условия.** Программа бесплатна: продавать её и просить за неё донаты нельзя, менять и раздавать можно бесплатно. Автор отвечает только за официальную версию из официального источника и не отвечает за чужие изменённые копии и код, добавленный в них. Текст всегда доступен командой `условия` и во вкладке «О программе».
- **FAQ.** Вкладка в настройках с ответами на частые вопросы.
- **О программе.** Версия, автор и официальный источник, условия, папки с данными (с кнопкой «Открыть»), список используемых компонентов и сведения для сообщения об ошибке одной кнопкой «Скопировать».

## Заметки

Каждая заметка это файл `<заголовок>.md` в общей папке, по умолчанию `Документы\SharedNotes`. Её можно сменить в настройках, в разделе «Заметки». Из-за такого формата заметки читаются и пишутся и в других программах: окно раз в пару секунд проверяет папку и подхватывает изменения. Если файл изменили снаружи во время вашей правки, ваша версия сохраняется отдельно с пометкой «конфликт», ничего не теряется.

- заметки открываются во вкладках (кнопка × закрывает вкладку), справа можно показать сведения о заметке: слова, символы, строки, дата изменения;
- текст остаётся обычным Markdown, но выглядит оформленным: крупные заголовки (`#`), **жирный**, *курсив*, `код`, ~~зачёркнутый~~, подчёркнутые ссылки, цитаты; чекбоксы `- [ ]` переключаются кликом, Enter продолжает список, Ctrl+клик по ссылке открывает её;
- панель форматирования: заголовки 1–3, жирный (Ctrl+B), курсив (Ctrl+I), списки, чекбокс, ссылка (Ctrl+K);
- поиск идёт по названию и по тексту;
- закрепление: кнопка «★ Закрепить» или Ctrl+P, закреплённые идут первыми (список закреплённых лежит в `.pins.json` внутри папки заметок);
- Ctrl+N: новая заметка, Ctrl+S: сохранить сразу (иначе сохраняется само);
- внизу окна счётчик слов и символов;
- в настройках: размер шрифта, задержка автосохранения, порядок в списке (по дате или по алфавиту).

## Темы

Тема это папка `themes/<имя>/` с файлом `theme.json` и необязательными картинками. Полное описание формата лежит в `themes/README.txt`: оно собирается из таблиц в `theme.py` и поэтому всегда совпадает с кодом.

В теме можно менять цвета (пары для светлого и тёмного режима), скругления, шрифты, картинку плюса, значки кнопок панели (`sidebar_command.png`, `sidebar_notes.png`, `sidebar_lock.png`, `sidebar_perf.png`, `sidebar_settings.png`) и текстуры кнопок (`texture_button.png`, `texture_button_hover.png`, `texture_active.png`). Если текстуры есть, кнопки панели становятся картинками, например металлическими.

Тему выбирают в настройках, в разделе «Темы»: карточки, кнопка «Добавить тему» и создание новой. Выбранная тема включается после перезапуска (есть кнопка «Перезапустить и применить»). Режим «тёмная, светлая или как в Windows» переключается сразу и работает с любой темой.

## Звуки

Положите файлы `.wav` или `.mp3` в папку `sounds` рядом с программой (она создаётся сама) и назовите их по событию. Регистр не важен. Нет файла: у события нет звука. Включение и громкость: «Настройки», «Общие», «Звуки».

| Файл | Когда играет |
|---|---|
| `launch` | запуск плитки |
| `error` | ошибка (плитка не запустилась, команда не выполнена) |
| `tile_add` | добавлена плитка |
| `tile_delete` | удалена плитка |
| `tile_move` | плитка переставлена |
| `select` | рамка выбора сдвинулась (стрелки, Tab) |
| `lock_on` | перетаскивание плиток заблокировано |
| `lock_off` | перетаскивание плиток разблокировано |
| `perf_on` | режим высокой производительности включён |
| `perf_off` | режим высокой производительности выключен |
| `window_show` | лаунчер показан (горячей клавишей или вторым запуском) |
| `window_hide` | лаунчер спрятан в фон |
| `settings_open` | открыты настройки |
| `settings_close` | закрыты настройки |
| `command` | появилась командная строка |
| `command_ok` | команда выполнена |
| `notes_open` | открыты заметки |
| `notes_close` | закрыты заметки |
| `note_new` | создана заметка |
| `note_delete` | удалена заметка |
| `click` | обычное нажатие кнопки; запасной звук для событий ниже, у которых нет своего файла |
| `nav` | переключён отдел настроек |
| `toggle_on` | переключатель в настройках включён |
| `toggle_off` | переключатель в настройках выключен |
| `option` | выбран вариант или сдвинут ползунок в настройках |
| `hotkey_set` | назначена новая горячая клавиша |
| `menu_open` | открыто меню плитки |
| `drag_start` | плитку взяли для перетаскивания |
| `hover` | курсор навели на плитку или кнопку панели (запасного звука нет) |
| `note_select` | выбрана другая заметка |
| `note_pin` | заметка закреплена |
| `note_unpin` | заметка откреплена |
| `cmd_move` | подсказка в командной строке сменилась (стрелки); запасной звук select |
| `cmd_complete` | подсказка подставлена (Tab) |
| `command_close` | командная строка закрыта клавишей Esc (запасного звука нет) |
| `theme_select` | выбрана тема |
| `color_set` | выбран цвет плитки |
| `faq_toggle` | открыт или закрыт ответ в FAQ |
| `copied` | текст скопирован (вкладка «О программе») |
| `note_save` | заметка сохранена вручную (Ctrl+S) |
| `type` | нажата клавиша в командной строке (запасного звука нет) |

Один файл `click` оживляет весь интерфейс: он играет вместо любого события, у которого нет своего файла (переключатели, меню, отделы настроек, выбор темы и т. д.), и на любую кнопку в окнах настроек и заметок. Хотите разнообразия, добавляйте файлы отдельным событиям. У `hover`, `command_close` и `type` запасного звука нет: они играют только если файл есть. Событие `cmd_move` по умолчанию играет `select`.

Актуальный список всегда лежит в самой папке в файле `имена_звуков.txt` (на английском `sound_names.txt`, на украинском `імена_звуків.txt`).

Заметки по звуку:

- Звуки играют через системный MCI (`winmm`), поэтому громкость лаунчера регулируется отдельно от системной.
- Каждый звук открывается заранее и играет свежим экземпляром: так нет задержки, а повторы звучат одинаково.
- Bluetooth-наушники после паузы «засыпают» и могут проглотить или исказить начало короткого звука. Это особенность наушников, а не лаунчера. Помогают звуки с небольшой тишиной в начале.

## Режим высокой производительности

Кнопка на панели (или команда `производительность`) переключает схему электропитания Windows на высокую производительность. Прежняя схема запоминается и возвращается при выключении.

## Где что лежит

Данные хранятся рядом с программой (рядом с `exe` в собранной версии) и переживают перезапуски.

| Что | Где |
|---|---|
| Плитки | `tiles.json` |
| Настройки | `settings.json` |
| Свои команды | `commands.json` |
| Избранные папки | `favorites.json` |
| История команд | `history.json` |
| Иконки плиток | `icons/` |
| Готовые иконки популярных программ | `icon_pack/` (файл с именем программы: `obs.png` подойдёт к `obs64.exe`) |
| Темы | `themes/` |
| Звуки | `sounds/` |
| Заметки | `Документы\SharedNotes` или папка из настроек |

Файлы данных пишутся через временный файл, поэтому закрытие посреди записи не портит их. Повреждённый JSON откладывается в сторону с расширением `.broken`, а не затирается.

### Как добавить язык

Русские строки в коде служат ключами: `tr("текст")` ищет перевод в таблице языка, а если не находит, показывает сам ключ. Чтобы добавить язык `xx`: создайте `lang_xx.py` с словарём `XX` (образец: `lang_en.py`), добавьте язык в `LANGS` в `i18n.py`, переведите тексты в `legal.py`, `faq_data.py` и названия событий в `sounds.py`.

Настройки, которые видны в окне, описаны в `settings_data.py`, заводские значения лежат в `config.DEFAULT_SETTINGS`. Новая настройка это строка в обоих местах.

## Сборка в exe

Сборка идёт через PyInstaller по файлу `main.spec`:

```
pip install pyinstaller
pyinstaller main.spec
```

Готовая программа появится в `dist\Aura NOX Launcher\` (сборка папкой, а не одним exe: антивирусы реже ругаются на неё; Qt делает папку заметно больше, чем была с CustomTkinter). Рядом с `Aura NOX Launcher.exe` лягут файлы данных, а папки `themes`, `sounds`, `icon_pack` нужно скопировать туда же, чтобы темы, звуки и готовые иконки работали.

## Если что-то не работает

- **Не нажимается горячая клавиша.** Комбинацию уже занимает другая программа. Лаунчер скажет об этом при запуске и отключит функцию; выберите другую комбинацию в настройках.
- **Нет звука.** Проверьте переключатель и громкость в «Настройки», «Общие», «Звуки», а также имя файла: оно должно совпадать с названием события.
- **Тема не применилась.** Тема включается после перезапуска: нажмите «Перезапустить и применить».
- **Лаунчер «пропал».** Он в фоновом режиме: вызовите его горячей клавишей или запустите `main.py` ещё раз.
