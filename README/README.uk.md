# Aura NOX Launcher

[Русский](README.ru.md) · [English](README.en.md)

Лаунчер для Windows на Python і PySide6 (Qt): вікно з плитками програм, права панель зі швидкими кнопками, командний рядок, нотатки, теми оформлення та звуки подій. Працює з клавіатури й мишею, може жити у фоні та викликатися гарячою клавішею.

## Можливості

- **Плитки.** Будь-яка програма, ярлик або `.bat` стає плиткою. Плитки можна переставляти мишею чи клавішами, фарбувати в будь-який колір, давати їм власні іконки. Іконка підбирається сама: з папки `icon_pack`, із самої програми або з ярлика.
- **Швидкі клавіші плиток.** У кожної плитки своя клавіша (цифри й літери, на будь-якій розкладці). Натискання одразу запускає плитку.
- **Права панель.** Кнопки налаштувань, командного рядка, нотаток, блокування перетягування та режиму високої продуктивності. Зайві кнопки можна сховати.
- **Командний рядок.** Викликається з будь-якої програми гарячою клавішею. Є вбудовані команди та власні, навігація по папках і файлах, обрані папки, швидкі нотатки та історія команд (див. нижче). Поки рядок відкритий, екран під ним розмивається й затемнюється (налаштовується, можна вимкнути).
- **Пошук програм.** Плитка з лупою (або сама «+», за налаштуванням) шукає програму за назвою серед ярликів меню «Пуск», робочого столу та програм із реєстру; якщо не знайшлося, можна пошукати на диску або вибрати файл вручну.
- **Три мови.** Русский, English, Українська. Мова обирається під час першого запуску й змінюється в налаштуваннях.
- **Нотатки.** Звичайні `.md`-файли в окремій папці: вкладки, живе оформлення Markdown, панель форматування, пошук за назвою й текстом, закріплення, автозбереження.
- **Пошук по налаштуваннях.** Рядок пошуку у вікні налаштувань знаходить потрібний пункт і прокручує до нього.
- **Теми.** Кольори, заокруглення, шрифти, картинки й текстури кнопок, світлий і темний режим.
- **Звуки.** Свій звук на кожну подію, загальна гучність і перемикач.
- **Фоновий режим.** Лаунчер ховається повністю й повертається гарячою клавішею. Автозапуск із Windows.
- **Довідка всередині.** Перший запуск з умовами та короткою інструкцією, вкладки «FAQ» і «Про програму» в налаштуваннях.
- **Один екземпляр.** Повторний запуск не створює друге вікно, а показує те, що вже працює.

## Вимоги

- Windows 10 або 11 (програма використовує виклики WinAPI).
- Python 3.13 (перевірено на ньому).
- Пакети: `PySide6`, `Pillow`.

```
pip install PySide6 pillow
```

## Запуск

```
python main.py
```

Ключ `--background` запускає лаунчер одразу схованим (його використовує автозапуск).

## Керування

### Головне вікно

| Клавіші | Дія |
|---|---|
| Стрілки | вибрати плитку; на панелі праворуч угору й униз обирають кнопку, ліворуч повертає до плиток |
| Tab | перенести вибір між плитками й панеллю |
| Enter | запустити плитку, додати програму на «+» (або відкрити пошук на лупі) чи натиснути кнопку панелі |
| Клавіша плитки | одразу запустити плитку |
| Delete | меню вибраної плитки (видалити, колір, іконка) |
| Правий клік | те саме меню для плитки під курсором |
| Ctrl + стрілки | перемістити вибрану плитку |
| Миша | затиснути плитку й потягнути, щоб помінятися місцями |
| F2 | налаштування |
| Ctrl+Q | повністю закрити лаунчер |

Перетягування можна заблокувати кнопкою ⇅ на панелі.

### Глобальні гарячі клавіші

Працюють з будь-якої програми. Усі три змінюються в налаштуваннях.

| За замовчуванням | Дія |
|---|---|
| Ctrl+Alt+Space | показати або сховати лаунчер (фоновий режим) |
| Ctrl+Alt+T | командний рядок |
| Ctrl+Alt+N | нотатки |

### Командний рядок

Tab підставляє підказку, стрілки вгору й униз обирають її, Enter виконує, PgUp і PgDn гортають довгу відповідь і сторінки підказок, Esc закриває. Якщо поле порожнє, стрілка вгору дістає попередні команди (останні 50, вони зберігаються між запусками), вниз повертає до новіших. Команда `help` показує весь список. Розмиття фону налаштовується в «Налаштування», «Зовнішній вигляд», «Додаткові налаштування», «Розмиття тла» (сила, затемнення, плавність; у світлій темі тло світлішає); клік по розмитому тлу закриває рядок. В англійському та українському інтерфейсі команди показуються англійськими іменами (`help`, `desk`, `calc`), російські імена працюють у будь-якій мові.

Вбудовані команди (в кожної є російське й англійське ім'я, таблиця показує обидва):

| Команда | Що робить |
|---|---|
| `помощь` / `help` | список команд |
| `настройки` / `settings`, `скрыть` / `hide`, `выход` / `exit` | керування самим лаунчером |
| `рб` / `desk` | віртуальні стільниці: `рб 2` перейти, `рб +` нова, `рб -` закрити |
| `окно` / `win` | перемкнутися на відкрите вікно |
| `громкость` / `vol` | системна гучність: `+`, `-`, `выкл` (вимкнути звук) |
| `блок` / `lock` | заблокувати комп'ютер |
| `выключить` / `shutdown`, `перезагрузить` / `restart`, `отмена` / `cancel` | вимкнення й перезавантаження із затримкою, щоб устигнути передумати |
| `производительность` / `perf` | режим високої продуктивності |
| `заметки` / `notes` | відкрити нотатки |
| `папка` / `folder` | папки й файли: `folder downloads\...`, пробіл після шляху покаже дії (див. нижче) |
| `избранное` / `favs` | обрані папки: `favs`, `favs remove name` |
| `запуск` / `run` | запустити плитку за назвою: `run obs` |
| `записать` / `jot` | швидка нотатка: `jot купити хліб` |
| `поиск` / `search` | пошук в інтернеті: `search погода` |
| `скрин` / `screenshot` | знімок екрана (вирізка Win+Shift+S) |
| `счёт` / `calc` | калькулятор: `calc 2+2*3` |
| `условия` / `terms` | умови використання |

**Власні команди** додаються в налаштуваннях, у розділі «Команди», і зберігаються в `commands.json`. Три види дій:

- **open**: відкрити програму, файл, папку або сайт;
- **set**: відкрити набір із кількох пунктів по черзі (по одному в рядку);
- **shell**: виконати команду командного рядка Windows.

У цілі можна написати `{}`: туди підставиться текст, введений після команди. Так виходять швидкі пошуки, наприклад `https://www.youtube.com/results?search_query={}` для команди `kk щось`.

### Папки й файли (команда `folder`)

Пишіть `folder downloads\`, і підказки покажуть, що всередині: Tab заходить у вибрану папку, `..\` піднімає на рівень вище, підказки гортаються PgUp і PgDn. Шлях починається з готової назви (`downloads`, `documents`, `desktop`, `pictures`, `videos`, `music`, `startup`, `home`), з диска (`c:`) або з назви з обраного. Enter відкриває папку в провіднику, а файл запускає.

Пробіл після цілого шляху показує дії над ним:

| Дія | Що робить |
|---|---|
| `open` | відкрити в провіднику (файл запустити) |
| `term` | термінал у цій папці |
| `code` | відкрити у VS Code |
| `path` | скопіювати шлях до буфера обміну |
| `show` | показати в провіднику |
| `ls` | що лежить усередині |
| `find текст` | знайти за назвою всередині, з підпапками |
| `new ім'я` | створити підпапку |
| `tile` | додати плиткою на головний екран |
| `pin` або `pin ім'я` | додати до обраного |

У дій є й російські назви (`открыть`, `терминал`, `код`, `путь`, `показать`, `список`, `найти`, `создать`, `плитка`, `закрепить`). Обрані папки зберігаються у `favorites.json`, а команда `favs` показує їхній список.

## Мова

Мови: російська, English, українська. Вибір з'являється під час першого запуску, потім його можна змінити в «Налаштування», «Загальні», «Мова». Після зміни лаунчер пропонує перезапуститися: тексти будуються під час старту. Назви мов: «Русский», «English», «Українська»; в англійському й українському інтерфейсі російська підписана просто «Ru».

Рядки без перекладу лаунчер показує російською, нічого не ламається.

## Перший запуск, умови, довідка

- **Перший запуск.** Вікно з трьох кроків: мова, умови використання, коротка інструкція. Показується один раз і знову лише якщо зміниться версія умов (у `settings.json` це поле `terms_seen`).
- **Умови.** Програма безкоштовна: продавати її й просити за неї донати не можна, змінювати й роздавати можна безкоштовно. Автор відповідає лише за офіційну версію з офіційного джерела й не відповідає за чужі змінені копії та код, доданий до них. Текст завжди доступний командою `terms` і у вкладці «Про програму».
- **FAQ.** Вкладка в налаштуваннях з відповідями на часті запитання.
- **Про програму.** Версія, автор і офіційне джерело, умови, папки з даними (з кнопкою «Відкрити»), список використаних компонентів і відомості для повідомлення про помилку однією кнопкою «Скопіювати».

## Нотатки

Кожна нотатка це файл `<заголовок>.md` у спільній папці, за замовчуванням `Документи\SharedNotes`. Її можна змінити в налаштуваннях, у розділі «Нотатки». Завдяки такому формату нотатки читаються й пишуться в інших програмах: вікно раз на кілька секунд перевіряє папку й підхоплює зміни. Якщо файл змінили ззовні під час вашого редагування, ваша версія зберігається окремо з позначкою «конфлікт», нічого не губиться.

- нотатки відкриваються у вкладках (кнопка × закриває вкладку), праворуч можна показати відомості про нотатку: слова, символи, рядки, дата зміни;
- текст лишається звичайним Markdown, але виглядає оформленим: великі заголовки (`#`), **жирний**, *курсив*, `код`, ~~закреслений~~, підкреслені посилання, цитати; чекбокси `- [ ]` перемикаються кліком, Enter продовжує список, Ctrl+клік по посиланню відкриває його;
- панель форматування: заголовки 1–3, жирний (Ctrl+B), курсив (Ctrl+I), списки, чекбокс, посилання (Ctrl+K);
- пошук іде за назвою й за текстом;
- закріплення: кнопка «★ Закріпити» або Ctrl+P, закріплені йдуть першими (список закріплених лежить у `.pins.json` усередині папки нотаток);
- Ctrl+N: нова нотатка, Ctrl+S: зберегти одразу (інакше зберігається саме);
- унизу вікна лічильник слів і символів;
- в налаштуваннях: розмір шрифту, затримка автозбереження, порядок у списку (за датою чи за алфавітом).

## Теми

Тема це папка `themes/<ім'я>/` з файлом `theme.json` і необов'язковими картинками. Повний опис формату лежить у `themes/README.txt`: він збирається з таблиць у `theme.py` і тому завжди збігається з кодом.

У темі можна змінювати кольори (пари для світлого й темного режиму), заокруглення, шрифти, картинку плюса, значки кнопок панелі (`sidebar_command.png`, `sidebar_notes.png`, `sidebar_lock.png`, `sidebar_perf.png`, `sidebar_settings.png`) і текстури кнопок (`texture_button.png`, `texture_button_hover.png`, `texture_active.png`). Якщо текстури є, кнопки панелі стають картинками, наприклад металевими.

Тему обирають у налаштуваннях, у розділі «Теми»: картки, кнопка «Додати тему» та створення нової. Вибрана тема вмикається після перезапуску (є кнопка «Перезапустити й застосувати»). Режим «темна, світла чи як у Windows» перемикається одразу й працює з будь-якою темою.

## Звуки

Покладіть файли `.wav` або `.mp3` у папку `sounds` поруч із програмою (вона створюється сама) і назвіть їх за подією. Регістр не важливий. Немає файла: у події немає звуку. Увімкнення й гучність: «Налаштування», «Загальні», «Звуки».

| Файл | Коли грає |
|---|---|
| `launch` | запущено плитку |
| `error` | помилка (плитка не запустилась, команда не виконалась) |
| `tile_add` | додано плитку |
| `tile_delete` | видалено плитку |
| `tile_move` | плитку переставлено |
| `select` | рамка вибору зсунулась (стрілки, Tab) |
| `lock_on` | перетягування плиток заблоковано |
| `lock_off` | перетягування плиток розблоковано |
| `perf_on` | режим високої продуктивності ввімкнено |
| `perf_off` | режим високої продуктивності вимкнено |
| `window_show` | лаунчер показано (гарячою клавішею або другим запуском) |
| `window_hide` | лаунчер сховано у фон |
| `settings_open` | відкрито налаштування |
| `settings_close` | закрито налаштування |
| `command` | з'явився командний рядок |
| `command_ok` | команду виконано |
| `notes_open` | відкрито нотатки |
| `notes_close` | закрито нотатки |
| `note_new` | створено нотатку |
| `note_delete` | видалено нотатку |
| `click` | звичайне натискання кнопки; запасний звук для подій нижче, які не мають свого файлу |
| `nav` | перемкнуто розділ налаштувань |
| `toggle_on` | перемикач у налаштуваннях увімкнено |
| `toggle_off` | перемикач у налаштуваннях вимкнено |
| `option` | обрано варіант або зсунуто повзунок у налаштуваннях |
| `hotkey_set` | призначено нову гарячу клавішу |
| `menu_open` | відкрито меню плитки |
| `drag_start` | плитку взято для перетягування |
| `hover` | курсор наведено на плитку або кнопку панелі (запасного звуку немає) |
| `note_select` | обрано іншу нотатку |
| `note_pin` | нотатку закріплено |
| `note_unpin` | нотатку відкріплено |
| `cmd_move` | підказка в командному рядку змінилась (стрілки); запасний звук select |
| `cmd_complete` | підказку підставлено (Tab) |
| `command_close` | командний рядок закрито клавішею Esc (запасного звуку немає) |
| `theme_select` | обрано тему |
| `color_set` | обрано колір плитки |
| `faq_toggle` | відкрито або закрито відповідь у FAQ |
| `copied` | текст скопійовано (вкладка «Про програму») |
| `note_save` | нотатку збережено вручну (Ctrl+S) |
| `type` | натиснуто клавішу в командному рядку (запасного звуку немає) |

Один файл `click` оживляє весь інтерфейс: він грає замість будь-якої події, у якої немає свого файлу (перемикачі, меню, розділи налаштувань, вибір теми тощо), і на будь-яку кнопку у вікнах налаштувань і нотаток. Хочете різноманітності, додавайте файли окремим подіям. У `hover`, `command_close` і `type` запасного звуку немає: вони грають лише якщо файл є. Подія `cmd_move` за замовчуванням грає `select`.

Актуальний список завжди лежить у самій папці у файлі `імена_звуків.txt` (російською `имена_звуков.txt`, англійською `sound_names.txt`).

Нотатки щодо звуку:

- Звуки грають через системний MCI (`winmm`), тому гучність лаунчера регулюється окремо від системної.
- Кожен звук відкривається заздалегідь і грає свіжим екземпляром: так немає затримки, а повтори звучать однаково.
- Bluetooth-навушники після паузи «засинають» і можуть проковтнути або спотворити початок короткого звуку. Це особливість навушників, а не лаунчера. Допомагають звуки з невеликою тишею на початку.

## Режим високої продуктивності

Кнопка на панелі (або команда `perf`) перемикає схему електроживлення Windows на високу продуктивність. Попередня схема запам'ятовується й повертається під час вимкнення.

## Де що лежить

Дані зберігаються поруч із програмою (поруч з `exe` у зібраній версії) і переживають перезапуски.

| Що | Де |
|---|---|
| Плитки | `tiles.json` |

### Як додати мову

Російські рядки в коді слугують ключами: `tr("текст")` шукає переклад у таблиці мови, а якщо не знаходить, показує сам ключ. Щоб додати мову `xx`: створіть `lang_xx.py` зі словником `XX` (зразок: `lang_en.py`), додайте мову до `LANGS` в `i18n.py`, перекладіть тексти в `legal.py`, `faq_data.py` і назви подій у `sounds.py`.

Налаштування, які видно у вікні, описані в `settings_data.py`, заводські значення лежать у `config.DEFAULT_SETTINGS`. Нове налаштування це рядок в обох місцях.

## Збірка в exe

Збірка йде через PyInstaller за файлом `main.spec`:

```
pip install pyinstaller
pyinstaller main.spec
```

Готова програма з'явиться в `dist\Aura NOX Launcher\` (збірка текою, а не одним exe: антивіруси рідше скаржаться на неї; Qt робить теку помітно більшою, ніж була з CustomTkinter). Поруч із `Aura NOX Launcher.exe` ляжуть файли даних, а теки `themes`, `sounds`, `icon_pack` потрібно скопіювати туди ж, щоб теми, звуки й готові іконки працювали.

## Якщо щось не працює

- **Не натискається гаряча клавіша.** Комбінацію вже займає інша програма. Лаунчер скаже про це під час запуску й вимкне функцію; оберіть іншу комбінацію в налаштуваннях.
- **Немає звуку.** Перевірте перемикач і гучність у «Налаштування», «Загальні», «Звуки», а також ім'я файла: воно має збігатися з назвою події.
- **Тема не застосувалася.** Тема вмикається після перезапуску: натисніть «Перезапустити й застосувати».
- **Лаунчер «зник».** Він у фоновому режимі: викличте його гарячою клавішею або запустіть `main.py` ще раз.
