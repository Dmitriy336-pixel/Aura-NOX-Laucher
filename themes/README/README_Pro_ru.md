ТЕМЫ ОФОРМЛЕНИЯ (ПРОДВИНУТАЯ ВЕРСИЯ)

Тема это папка внутри «themes». Выбрать тему: Настройки -> Темы -> нажать на карточку -> «Перезапустить и применить».
Папка «themes» лежит рядом с main.py (при запуске из VS Code) или рядом с exe (в собранной версии).

КАК СДЕЛАТЬ СВОЮ ТЕМУ
  Способ 1: Настройки -> Темы -> «Создать свою». Появится папка с готовым theme.json, где уже есть все ключи.
  Способ 2: скопируй папку _template, назови как хочешь (имя без _ и точки в начале).
  Дальше открой theme.json и поменяй нужное. Лишние ключи можно удалить: пропущенное берётся стандартное.
  Положи свой icon.png (картинка карточки). Без него карточка покажет макет, нарисованный по цветам темы.
  Настройки -> Темы -> «Обновить список». Тема вне themes добавляется кнопкой «＋ Добавить тему» (копируется).
  Папки, имя которых начинается с _ или точки, в список не попадают (так спрятан шаблон).

ФОРМАТ theme.json
  { "name": "Название в списке", "colors": {...}, "shapes": {...}, "fonts": {...}, "tiles": {"palette": [...]} }
  Цвет это пара [светлая, тёмная] вида "#rrggbb". Одна строка "#rrggbb" значит один цвет для обеих тем.
  Неверное значение пропускается и берётся стандартное.

ЦВЕТА (colors)
  button             обычная кнопка (а также ползунки, переключатели, выбор вариантов)
  button_hover       кнопка под курсором
  button_text        текст на обычной кнопке
  button_border      рамка кнопок с обводкой
  active             включённая функция: подсвеченная кнопка правой панели
  active_hover       включённая кнопка под курсором
  select_border      рамка выбранной кнопки правой панели
  ghost_text         текст на прозрачных кнопках (список разделов, «Сброс», «Отмена»)
  ghost_hover        прозрачная кнопка под курсором
  danger             кнопки «Удалить» и «Сбросить всё»
  danger_hover       кнопка «Удалить» под курсором
  window_bg          фон окон
  panel_bg           фон панелей и рамок
  panel_top_bg       фон панелей внутри панелей
  card_bg            строки списков и карточки тем
  card_hover         строка или карточка под курсором
  nav_selected       выбранный раздел в списке настроек слева
  select_bg          выбранная строка: заметка в списке, подсказка в командной строке
  help_badge         кружок «?» с подсказкой
  help_text          знак в кружке «?»
  text               обычный текст
  text_dim           приглушённый текст: описания, подписи, подсказки
  accent             выделенный текст: названия команд, быстрые клавиши в списках
  error              сообщения об ошибках
  entry_bg           фон полей ввода
  entry_border       рамка полей ввода
  entry_text         текст в полях ввода
  entry_placeholder  серая подсказка в пустом поле
  textbox_bg         фон большого текстового поля (редактор заметок)
  textbox_border     рамка большого текстового поля
  textbox_text       текст заметки
  scrollbar          ползунок полосы прокрутки
  scrollbar_hover    ползунок полосы прокрутки под курсором
  switch_off         выключенный переключатель
  switch_knob        кружок на переключателе
  slider_track       дорожка ползунка
  dropdown_bg        выпадающий список: фон
  dropdown_hover     выпадающий список: строка под курсором
  dropdown_text      выпадающий список: текст
  segmented_bg       переключатель из нескольких кнопок: фон и невыбранные
  segmented_hover    невыбранная кнопка под курсором
  cmd_panel_bg       командная строка: панель с подсказками
  cmd_box_bg         командная строка: фон окна
  cmd_line           командная строка: рамка и разделители
  tile_border        рамка плитки «＋»
  tile_select        рамка выбранной плитки
  tile_text_light    текст на тёмных плитках
  tile_text_dark     текст на светлых плитках
  caption            подпись под плиткой
  drag_source        рамка плитки, которую тащат
  drag_target        рамка плитки, на чьё место встанет перетаскиваемая
  tooltip_bg         всплывающая подсказка: фон
  tooltip_text       всплывающая подсказка: текст

СКРУГЛЕНИЯ (shapes), число от 0 до 40
  button_radius      скругление кнопок
  frame_radius       скругление панелей
  entry_radius       скругление полей ввода и текстовых полей
  tile_radius        скругление плиток
  sidebar_radius     скругление кнопок правой панели
  texture_inset      отступ текстуры кнопок панели от края, px (если края картинки обрезаются, поставь 2)

ШРИФТ (fonts)
  family             название шрифта, например Segoe UI
  size               основной размер текста, 8..24
  icon_family        шрифт значков на кнопках правой панели (по умолчанию Segoe UI Symbol)

ПАЛИТРА ПЛИТОК (tiles.palette)
  Список цветов #rrggbb (до 24): новые плитки получают их по кругу, они же в окне выбора цвета плитки.

КАРТИНКИ (png или webp, лучше квадратные, от 128x128, с прозрачностью)
  icon.png              картинка карточки темы в настройках (256x256)
  plus.png              значок на плитке «＋»
  sidebar_command.png   кнопка командной строки
  sidebar_notes.png     кнопка заметок
  sidebar_lock.png      кнопка блокировки плиток
  sidebar_perf.png      кнопка режима производительности
  sidebar_settings.png  кнопка настроек
  Для светлой и тёмной темы можно положить разные: plus_light.png и plus_dark.png.
  Текстуры кнопок правой панели (картинка вместо цветной заливки, значок рисуется поверх):
  texture_button.png        обычная кнопка (без этого файла текстур нет, кнопки остаются цветными)
  texture_button_hover.png  кнопка под курсором (нет файла: та же текстура, чуть светлее)
  texture_active.png        включённая функция (нет файла: та же текстура, подкрашенная цветом active)
  Значок берётся из sidebar_<имя>.png, а если его нет, рисуется символ кнопки шрифтом icon_family.
  Картинка обрезается до квадрата и скругляется по sidebar_radius. Если края текстуры обрезаются,
  поставь shapes.texture_inset = 2.
  Нет картинки, остаётся обычный значок.
