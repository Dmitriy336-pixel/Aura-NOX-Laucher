ТЕМЫ ОФОРМЛЕНИЯ (ОБЛЕГЧЕНАЯ ВЕРСИЯ)

Тема это папка внутри «themes». Выбрать тему: Настройки -> Темы -> нажать на карточку -> «Перезапустить и применить».
Папка «themes» должна лежать рядом с main.py (при запуске из VS Code) или рядом с exe (в собранной версии).

КАК СДЕЛАТЬ СВОЮ ТЕМУ
  1. Скопируй папку _template, назови её как хочешь (имя без _ в начале).
  2. Открой theme.json и поменяй название и цвета.
  3. Положи свой icon.png (картинка карточки). Без него карточка покажет макет, нарисованный по цветам темы.
  4. Настройки -> Темы -> «Обновить список». Если тема лежит вне themes, нажми «＋ Добавить тему»: она скопируется.
  Папки, имя которых начинается с _ или точки, в список не попадают (так спрятан шаблон).

theme.json
  {
    "name": "Название в списке",
    "colors": { "button": ["#светлая", "#тёмная"], ... }
  }
  Цвет задаётся парой: первый для светлой темы, второй для тёмной. Одна строка "#rrggbb" значит один цвет для обеих.
  Пропущенный цвет берётся стандартный. Неверный цвет пропускается.

Цвета
  button, button_hover, button_text    обычные кнопки, их цвет под курсором и цвет текста на них
  active, active_hover                 включённая функция: подсвеченная кнопка на правой панели
  select_border                        рамка выбранной кнопки панели
  window_bg                            фон окон            (необязательный)
  panel_bg, panel_top_bg               фон панелей и вложенных панелей  (необязательные)
  text                                 цвет обычного текста  (необязательный)

Картинки (png или webp, лучше квадратные, от 128x128, с прозрачностью)
  icon.png                             картинка карточки темы в настройках (256x256)
  plus.png                             значок на плитке «+»
  sidebar_command.png                  кнопка командной строки
  sidebar_notes.png                    кнопка заметок
  sidebar_lock.png                     кнопка блокировки плиток
  sidebar_perf.png                     кнопка режима производительности
  sidebar_settings.png                 кнопка настроек
  Для светлой и тёмной темы можно положить разные: plus_light.png и plus_dark.png.
  Нет картинки, остаётся обычный значок.
