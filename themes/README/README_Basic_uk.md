ТЕМИ ОФОРМЛЕННЯ (ПОЛЕГШЕНА ВЕРСІЯ)

Тема — це папка всередині «themes». Вибрати тему: Налаштування -> Теми -> натиснути на картку -> «Перезапустити та застосувати».
Папка «themes» повинна лежати поруч із main.py (при запуску з VS Code) або поруч з exe (у зібраній версії).

ЯК ЗРОБИТИ ВЛАСНУ ТЕМУ
  1. Скопіюй папку _template, назви її як завгодно (ім'я без _ на початку).
  2. Відкрий theme.json і зміни назву та кольори.
  3. Поклади свій icon.png (картинка картки). Без нього картка покаже макет, намальований за кольорами теми.
  4. Налаштування -> Теми -> «Оновити список». Якщо тема лежить поза themes, натисни «＋ Додати тему»: вона скопіюється.
  Папки, ім'я яких починається з _ або крапки, до списку не потрапляють (так сховано шаблон).

theme.json
  {
    "name": "Назва у списку",
    "colors": { "button": ["#світла", "#темна"], ... }
  }
  Колір задається парою: перший для світлої теми, другий для темної. Один рядок "#rrggbb" означає один колір для обох.
  Пропущений колір береться стандартний. Невірний колір пропускається.

Кольори
  button, button_hover, button_text     звичайні кнопки, їх колір під курсором і колір тексту на них
  active, active_hover                  увімкнена функція: підсвічена кнопка на правій панелі
  select_border                         рамка вибраної кнопки панелі
  window_bg                             фон вікон           (необов'язковий)
  panel_bg, panel_top_bg                фон панелей і вкладених панелей  (необов'язкові)
  text                                  колір звичайного тексту  (необов'язковий)

Картинки (png або webp, краще квадратні, від 128x128, з прозорістю)
  icon.png                              картинка картки теми в налаштуваннях (256x256)
  plus.png                              значок на плитці «+»
  sidebar_command.png                   кнопка командного рядка
  sidebar_notes.png                     кнопка нотаток
  sidebar_lock.png                      кнопка блокування плиток
  sidebar_perf.png                      кнопка режиму продуктивності
  sidebar_settings.png                  кнопка налаштувань
  Для світлої і темної теми можна покласти різні: plus_light.png та plus_dark.png.
  Немає картинки — залишається звичайний значок.
