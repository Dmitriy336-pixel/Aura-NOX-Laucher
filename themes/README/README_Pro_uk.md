ТЕМИ ОФОРМЛЕННЯ (ПРОСВІТЛЕНА / ПРОДВИНУТА ВЕРСІЯ)

Тема — це папка всередині «themes». Вибрати тему: Налаштування -> Теми -> натиснути на картку -> «Перезапустити та застосувати».
Папка «themes» лежить поруч із main.py (при запуску з VS Code) або поруч з exe (у зібраній версії).

ЯК ЗРОБИТИ ВЛАСНУ ТЕМУ
  Спосіб 1: Налаштування -> Теми -> «Створити свою». З'явиться папка з готовим theme.json, де вже є всі ключі.
  Спосіб 2: скопіюй папку _template, назви як завгодно (ім'я без _ та крапки на початку).
  Далі відкрий theme.json і зміни потрібне. Зайві ключі можна видалити: пропущене береться стандартне.
  Поклади свій icon.png (картинка картки). Без нього картка покаже макет, намальований за кольорами теми.
  Налаштування -> Теми -> «Оновити список». Тема поза themes додається кнопкою «＋ Додати тему» (копіюється).
  Папки, ім'я яких починається з _ або крапки, до списку не потрапляють (так сховано шаблон).

ФОРМАТ theme.json
  { "name": "Назва у списку", "colors": {...}, "shapes": {...}, "fonts": {...}, "tiles": {"palette": [...]} }
  Колір — це пара [світла, темна] виду "#rrggbb". Один рядок "#rrggbb" означає один колір для обох тем.
  Невірне значення пропускається і береться стандартне.

  active_hover       увімкнена кнопка під курсором
  select_border      рамка вибраної кнопки правої панелі
  ghost_text         текст на прозорих кнопках (список розділів, «Скидання», «Скасувати»)
  ghost_hover        прозора кнопка під курсором
  danger             кнопки «Видалити» та «Скинути все»
  danger_hover       кнопка «Видалити» під курсором
  window_bg          фон вікон
  panel_bg           фон панелей і рамок
  panel_top_bg       фон панелей всередині панелей
  card_bg            рядки списків та картки тем

  nav_selected       вибраний розділ у списку налаштувань ліворуч

  help_badge         кружок «?» з підказкою
  help_text          знак у кружку «?»
  text               звичайний текст

  entry_bg           фон полів введення
  entry_border       рамка полів введення
  entry_text         текст у полях введення
  entry_placeholder  сіра підказка в порожньому полі

  textbox_border     рамка великого текстового поля
  textbox_text       текст нотатки
  scrollbar          повзунок смуги прокручування
  scrollbar_hover    повзунок смуги прокручування під курсором

  tooltip_text       спливаюча підказка: текст

ЗАКРУГЛЕННЯ (shapes), число від 0 до 40
  button_radius      закруглення кнопок
  frame_radius       закруглення панелей
  entry_radius       закруглення полів введення і текстових полів
  tile_radius        закруглення плиток
  sidebar_radius     закруглення кнопок правої панелі
  texture_inset      відступ текстури кнопок панелі від краю, px (якщо краї картинки обрізаються, постав 2)

ШРИФТ (fonts)
  family             назва шрифту, наприклад Segoe UI
  size               основний розмір тексту, 8..24
  icon_family        шрифт значків на кнопках правої панелі (за замовчуванням Segoe UI Symbol)

ПАЛІТРА ПЛИТОК (tiles.palette)
  Список кольорів #rrggbb (до 24): нові плитки отримують їх по колу, вони ж у вікні вибору кольору плитки.

КАРТИНКИ (png або webp, краще квадратні, від 128x128, з прозорістю)
  icon.png               картинка картки теми в налаштуваннях (256x256)
  plus.png               значок на плитці «＋»
  sidebar_command.png    кнопка командного рядка
  sidebar_notes.png      кнопка нотаток
  sidebar_lock.png       кнопка блокування плиток
  sidebar_perf.png       кнопка режиму продуктивності
  sidebar_settings.png   кнопка налаштувань
  Для світлої і темної теми можна покласти різні: plus_light.png та plus_dark.png.
  Текстури кнопок правої панелі (картинка замість кольорового заповнення, значок малюється поверх):
  texture_button.png         звичайна кнопка (без цього файлу текстур немає, кнопки залишаються кольоровими)
  texture_button_hover.png   кнопка під курсором (немає файлу: та сама текстура, трохи світліша)
  texture_active.png         увімкнена функція (немає файлу: та сама текстура, підфарбована кольором active)
  Значок береться з sidebar_<ім'я>.png, а якщо його немає, малюється символ кнопки шрифтом icon_family.
  Картинка обрізається до квадрата і закруглюється за sidebar_radius. Якщо краї текстури обрізаються,
  постав shapes.texture_inset = 2.
  Немає картинки — залишається звичайний значок.
